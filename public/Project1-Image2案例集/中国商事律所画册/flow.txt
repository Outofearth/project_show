Point 01｜先拆结构：按真实商业画册的逻辑来规划

不要一上来就让 GPT 随便生成几页，先把画册拆成真实商业物料结构：

1、封面 / 封底
建立品牌门面、行业气质和整体视觉调性
2、企业介绍页
说明公司定位、能力边界和服务对象

3、产品技术页
展示核心产品、技术优势和解决方案
4、应用场景页
让用户看到产品能用在哪些行业

5、案例 / 合作页
补充可信度和商业转化信息
6、全册系统预览
验证风格是否统一，是否像一整本画册

核心是让 GPT 连续生成一套「结构完整、风格统一、可以商用展示」的企业物料。

Point 02｜通用提示词框架：替换成你自己的行业和品牌

请生成一套企业级商用画册视觉方案，主题为【品牌名称】的【行业 / 产品 / 解决方案】宣传画册。

整体风格：高端、专业、具有强视觉冲击力，不要传统 Word 排版感，不要普通 PPT 感。采用【深色科技美学 / 白色极简商务 / 高端工业风 / 艺术化品牌画册】风格。

画册内容包括：
1、封面与封底
2、企业介绍与品牌理念
3、核心产品与技术优势
4、应用场景与解决方案
5、客户案例与合作方式
6、全册系统预览图

要求：
版式要有设计感，图片、标题、数据、图标、留白和层级关系清晰；保持整套画册统一的品牌视觉系统；重点体现真实商业物料的完成度，而不是简单文字排版。

Point 03｜已有资料怎么用：上传旧画册 / PPT / 官网内容重新规划

如果你已经有企业资料，也可以直接上传给 ChatGPT：

1、旧版企业画册
2、公司介绍文档
3、产品说明书
4、官网内容
5、PPT 提案
6、产品图片 / 案例图片
然后让它做三件事：
1、重新梳理内容结构
判断哪些内容适合做封面、企业介绍、产品页、案例页和合作页。
2、提炼画册主线
不要只是堆资料，而是形成清晰的商业叙事。
3、统一视觉方向
让整本画册看起来像同一个品牌系统，而不是不同页面拼起来。
几个避坑：

1、不要一上来就说“生成一本画册”，容易变成模板图。
2、不要只堆文字，画册一定要有产品视觉、场景图、数据模块和设计层级。
3、不要只生成单页，最好补一张全册预览图，才能体现完整系统感。

2、律所 / 会计师事务所画册的专用结构：

律所、会计师事务所这类高信任行业，客户更关心的是：

1、这家机构是否专业、稳重、可信？
2、核心业务和服务边界是否清晰？
3、是否懂我的行业和实际问题？
4、团队能力、方法论、服务流程是否成熟？
5、有没有代表性经验和长期服务能力？
6、整体品牌形象是否足够让客户放心合作？

所以生成这类画册时，要先拆成：

封面封底 / 机构简介 / 品牌理念 / 核心业务领域 / 行业解决方案 / 服务流程 / 专业团队 / 代表案例 / 服务网络 / 联系方式 / 全册预览

如果是律所，可以重点放：
公司治理、投融资并购、争议解决、劳动人事、知识产权、数据合规、行业方案、服务方法论。

如果是会计师事务所，可以重点放：
审计鉴证、税务筹划、财务咨询、内控合规、并购重组、尽职调查、企业估值、行业服务、项目流程。

核心是把「机构定位、业务矩阵、行业能力、服务方法论和客户信任感」统一成一套专业品牌画册。
