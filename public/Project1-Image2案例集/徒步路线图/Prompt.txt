生成「路线名称」徒步路线图。

整体风格参考手绘3D地形旅行攻略地图，不是卫星地图，也不是普通风景插画，而是结合山地插画、路线示意图、旅行信息图的高可读性攻略图。画面需要兼具自然风景的美感与清晰路线指引功能，其中路线必须是视觉中心，优先级高于风景，不能让风景喧宾夺主。

画面采用倾斜俯视角 / 鸟瞰视角，展现整条徒步路线所在区域的核心地貌，包括【山峰 / 峡谷 / 河流 / 森林 / 草甸 / 湖泊 / 村庄 / 瀑布 / 山脊 / 观景平台】等元素。整体要有自然风景的层次和氛围，但不能变成单纯的风景画，而是要始终服务于路线表达。

请用粗而清晰、颜色鲜明的路线线条标出路线，不同路线或支线用不同颜色区分，并配有明显箭头表示前进方向。路线必须连续、醒目，不被山体、树木、云雾或装饰遮挡，让徒步新手也能一眼看懂从哪里出发、经过哪里、最终到哪里。路线的可读性必须非常强，不能画得太细，也不能模糊不清。

请在地图中清晰标出完整的攻略信息，包括主标题，如“【路线名称】徒步路线图”，以及副标题，如“经典路线示意 / 新手攻略 / 精华路线”。同时需要标出起点、终点、主要途经点、休息点、观景点、补给点 / 厕所 / 住宿点（如有）、危险路段 / 陡坡 / 临崖路段（如有）、支线或可选路线（如有），并加入图例说明、推荐玩法 / 推荐行程、全程距离、预计用时、难度等级，以及温馨提示 / 徒步建议等信息，让整张图具备明显的旅行攻略属性。

每个节点旁边都要放置简洁清晰的标签卡片，标签中显示地点名称、距离、预计时间、海拔（可选）等信息。标签要像旅行攻略中的说明贴纸，简洁、整齐、容易阅读，不要出现复杂大段文字，也不要堆砌过多小字，重点是让人快速获取关键信息。

整体视觉风格要求偏向手绘3D地形地图、旅行攻略信息图和高级户外路线示意图，带有轻微手账感，自然配色，排版清晰，层级分明，可读性强，适合小红书 / 公众号 / 旅行攻略封面使用。整体气质要清爽、实用、好看，既有地图感，也有攻略信息图的视觉完成度。

版式上，画面主体为地图，路线居中且突出。左侧或下方可以放“图例 / 推荐玩法 / 距离时间 / 难度”等信息模块，右下角可放“温馨提示”。标题要醒目，但不要压住地图主体。整体画面要清爽，不拥挤，不杂乱，信息虽然完整，但不能显得堆砌和凌乱。

请特别注意：不要生成真实卫星地图，不要过度艺术化导致看不懂，不要把路线画得太细，不要让山体遮住路线，不要使用复杂难辨认的小字，不要让文字过多，不要只做风景画。路线必须比风景更重要，必须有明显的信息图属性。最终效果要像一张可以直接发在社媒上的高质量徒步攻略图。
